# Security Policy

## Reporting Security Issues

We take the security of this project and related infrastructure seriously. If you discover a security vulnerability or potential exposure, please report it responsibly.

### Guidelines
- **Do not** disclose or discuss vulnerabilities publicly (e.g. in public issues, discussions, or social media) until a fix has been released.
- Please provide detailed steps to reproduce the issue, along with proof-of-concept material where applicable.
- Reports will be acknowledged, investigated, and remediated in subsequent updates.

Thank you for helping keep this project secure!
